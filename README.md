# Epstein Email Co-presence Network

This repository contains a reproducible text-mining and network-analysis package for the Epstein email archive. The `prelim_submission` branch has been adapted for the BUSS425 informal network centrality assignment, with a weighted co-presence graph, centrality interpretation, visualization, and adjacency-matrix outputs.

The GitHub Pages report lives in `docs/index.md`. Reproducible outputs are stored under `outputs/ms3/` and `outputs/buss425/`.
